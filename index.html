Get all recipes stored in the database.

GET /recipes

No request body is required.

Returns an array containing all recipes.

GET /recipes/:id

Get one recipe using its recipe ID.

Request

GET /recipes/1

Replace 1 with the ID of the recipe you want to retrieve.

Expected result — 200:

Returns one recipe object.

Example Response

{
  "id": 1,
  "name": "Fried Rice",
  "ingredients": "2 cups cooked rice, 2 eggs, 1 carrot, 2 spring onions, 2 cloves garlic, 1 tbsp soy sauce, 1 tbsp cooking oil, 1/2 tsp salt",
  "instructions": "1. Heat the wok over medium-high heat and add the cooking oil. 2. Add garlic and carrot, then stir-fry for 1-2 minutes. 3. Push the vegetables to one side and crack in the eggs. Scramble until cooked. 4. Add the cooked rice and stir-fry everything together. 5. Add soy sauce and salt, then toss well. 6. Add spring onions and stir-fry for another minute. Serve hot.",
  "author": "Jonathan",
  "category": "Vegetarian"
}
Error example — 400: Invalid ID 
GET /recipes/abc
{
  "error": "Recipe ID must be a number"
}
Error example — 404: Recipe not found 
GET /recipes/99999
{
  "error": "Recipe not found"
}
Error example — 500: Database error 
{
  "error": "Failed to get recipe"
}

POST /recipes

Create a new recipe and store it in the database.

The author ID and category ID must already exist in the database.

Request

POST /recipes

Request Body

{
  "name": "Chicken Teriyaki",
  "ingredients": "2 chicken thighs, 3 tbsp soy sauce, 2 tbsp mirin, 1 tbsp honey, 2 cloves garlic, 1 tsp grated ginger, 1 tbsp cooking oil, 1 spring onion",
  "author_id": 6,
  "category_id": 6,
  "instructions": "1. Mix soy sauce, mirin, honey, garlic and ginger to make the teriyaki sauce. 2. Heat the cooking oil in a pan and cook the chicken until golden brown. 3. Pour in the teriyaki sauce and simmer until the chicken is cooked through. 4. Turn the chicken to coat it evenly with the sauce. 5. Slice the chicken and garnish with spring onion."
}
Expected result — 201:

Returns the newly created recipe.

Example Response

{
  "id": 7,
  "name": "Chicken Teriyaki",
  "ingredients": "2 chicken thighs, 3 tbsp soy sauce, 2 tbsp mirin, 1 tbsp honey, 2 cloves garlic, 1 tsp grated ginger, 1 tbsp cooking oil, 1 spring onion",
  "author_id": 6,
  "category_id": 6,
  "instructions": "1. Mix soy sauce, mirin, honey, garlic and ginger to make the teriyaki sauce. 2. Heat the cooking oil in a pan and cook the chicken until golden brown. 3. Pour in the teriyaki sauce and simmer until the chicken is cooked through. 4. Turn the chicken to coat it evenly with the sauce. 5. Slice the chicken and garnish with spring onion."
}
Error example — 400: Missing fields 
POST /recipes

{
  "name": "Chicken Teriyaki"
}
{
  "error": "All recipe fields are required"
}
Error example — 400: Invalid foreign key 
POST /recipes

{
  "name": "Chicken Teriyaki",
  "ingredients": "Chicken, soy sauce, mirin",
  "author_id": 999,
  "category_id": 999,
  "instructions": "Cook the chicken with the sauce."
}
{
  "error": "Author or category does not exist"
}
Error example — 500: Database error 
{
  "error": "Failed to create recipe"
}

POST /users

Create a new user.

The user can then be used as an author when creating a recipe.

Request

POST /users

Request Body

{
  "name": "Sarah Lee",
  "email": "sarah@mail.com"
}
Expected result — 201:

Returns the newly created user.

Example Response

{
  "id": 4,
  "name": "Sarah Lee",
  "email": "sarah@mail.com"
}
Error example — 400: Missing fields 
POST /users

{
  "name": "Sarah Lee"
}
{
  "error": "Name and email are required"
}
Error example — 400: Duplicate email 
POST /users

{
  "name": "Jonathan",
  "email": "johnathan@mail.com"
}
{
  "error": "Email already exists"
}
Error example — 500: Database error 
{
  "error": "Failed to create user"
}
