API Documentation

GET /recipes

Get all recipes stored in the database.

Request

GET /recipes

No request body is required.

Expected result:

Returns an array containing all recipes.

Example Response

[
  {
    "id": 1,
    "name": "FireWok Vegetable Noodles",
    "ingredients": "Noodles, broccoli, carrot, garlic",
    "instructions": "Heat the wok, stir fry the garlic and vegetables, then add noodles and toss until cooked.",
    "author": "Ong Chuu Harn",
    "category": "Vegetarian"
  }
]
Error example — 500: 
{
  "error": "Failed to get recipes"
}

GET /recipes/:id

Get one recipe using its recipe ID.

Request

GET /recipes/1

Replace 1 with the ID of the recipe you want to retrieve.

Expected result:

Returns one recipe object.

Example Response — 200

{
  "id": 1,
  "name": "FireWok Vegetable Noodles",
  "ingredients": "Noodles, broccoli, carrot, garlic",
  "instructions": "Heat the wok, stir fry the garlic and vegetables, then add noodles and toss until cooked.",
  "author": "Ong Chuu Harn",
  "category": "Vegetarian"
}
Error example — 400: Invalid ID 
GET /recipes/abc
{
  "error": "Recipe ID must be a number"
}
Error example — 404: Recipe not found 
GET /recipes/99999
{
  "error": "Recipe not found"
}
Error example — 500: Database error 
{
  "error": "Failed to get recipe"
}

POST /recipes

Create a new recipe and store it in the database.

The author ID and category ID must already exist in the database.

Request

POST /recipes

Request Body

{
  "name": "FireWok Fried Rice",
  "ingredients": "Rice, egg, carrot, spring onion",
  "author_id": 1,
  "category_id": 1,
  "instructions": "Heat the wok and fry all ingredients."
}
Expected result — 201:

Returns the newly created recipe.

Example Response

{
  "id": 4,
  "name": "FireWok Fried Rice",
  "ingredients": "Rice, egg, carrot, spring onion",
  "author_id": 1,
  "category_id": 1,
  "instructions": "Heat the wok and fry all ingredients."
}
Error example — 400: Missing fields 
POST /recipes

{
  "name": "FireWok Fried Rice"
}
{
  "error": "All recipe fields are required"
}
Error example — 400: Invalid foreign key 
POST /recipes

{
  "name": "FireWok Fried Rice",
  "ingredients": "Rice, egg, carrot",
  "author_id": 999,
  "category_id": 999,
  "instructions": "Heat the wok and fry all ingredients."
}
{
  "error": "Author or category does not exist"
}
Error example — 500: Database error 
{
  "error": "Failed to create recipe"
}

GET /users

Get all users stored in the database.

Users can be used as recipe authors.

Request

GET /users

No request body is required.

Expected result — 200:

Returns an array containing all users.

Example Response

[
  {
    "id": 1,
    "name": "Ong Chuu Harn",
    "email": "chuu@example.com"
  },
  {
    "id": 2,
    "name": "Amy Tan",
    "email": "amy@example.com"
  }
]
Error example — 500: 
{
  "error": "Failed to get users"
}

POST /users

Create a new user.

The user can then be used as an author when creating a recipe.

Request

POST /users

Request Body

{
  "name": "John",
  "email": "john@example.com"
}
Expected result — 201:

Returns the newly created user.

Example Response

{
  "id": 4,
  "name": "John",
  "email": "john@example.com"
}
Error example — 400: Missing fields 
POST /users

{
  "name": "John"
}
{
  "error": "Name and email are required"
}
Error example — 400: Duplicate email 
POST /users

{
  "name": "John",
  "email": "chuu@example.com"
}
{
  "error": "Email already exists"
}
Error example — 500: Database error 
{
  "error": "Failed to create user"
}

GET /categories

Get all recipe categories stored in the database.

Categories are used when creating recipes.

Request

GET /categories

No request body is required.

Expected result — 200:

Returns an array containing all categories.

Example Response

[
  {
    "id": 1,
    "name": "Vegetarian"
  },
  {
    "id": 2,
    "name": "Vegan"
  },
  {
    "id": 3,
    "name": "Pescatarian"
  }
]
Error example — 500: 
{
  "error": "Failed to get categories"
}
