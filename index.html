API Documentation

API URLs

Local API: http://localhost:4000

Hosted API: https://firewok-api-production.up.railway.app

GET /recipes

Request:

GET http://localhost:4000/recipes

GET https://firewok-api-production.up.railway.app/recipes

Expected Result:

Returns all recipes.

Example Response:

[
    {
        "id": 1,
        "name": "Fried Rice",
        "ingredients": "2 cups cooked rice, 2 eggs, 1 carrot",
        "author_id": 1,
        "category_id": 1,
        "instructions": "1. Heat the wok. 2. Add the ingredients."
    }
]

Error Example:

{
    "error": "Failed to get recipes"
}

GET /recipes/:id

Request:

GET http://localhost:4000/recipes/1

GET https://firewok-api-production.up.railway.app/recipes/1

Expected Result:

Returns one recipe by ID.

Example Response:

{
    "id": 1,
    "name": "Fried Rice",
    "ingredients": "2 cups cooked rice, 2 eggs, 1 carrot",
    "author_id": 1,
    "category_id": 1,
    "instructions": "1. Heat the wok. 2. Add the ingredients."
}

Error Examples:

{
    "error": "Recipe not found"
}
{
    "error": "Recipe ID must be a number"
}

POST /recipes

Request:

POST http://localhost:4000/recipes

POST https://firewok-api-production.up.railway.app/recipes

Request Body:

{
    "name": "Chicken Teriyaki",
    "ingredients": "Chicken, soy sauce, sugar, garlic",
    "author_id": 6,
    "category_id": 6,
    "instructions": "1. Cook the chicken. 2. Add the sauce."
}

Expected Result:

Creates a new recipe and returns the created recipe.

Example Response:

{
    "id": 9,
    "name": "Chicken Teriyaki",
    "ingredients": "Chicken, soy sauce, sugar, garlic",
    "author_id": 6,
    "category_id": 6,
    "instructions": "1. Cook the chicken. 2. Add the sauce."
}

Error Examples:

{
    "error": "All recipe fields are required"
}
{
    "error": "Author or category does not exist"
}
{
    "error": "Failed to create recipe"
}

POST /users

Request:

POST http://localhost:4000/users

POST https://firewok-api-production.up.railway.app/users

Request Body:

{
